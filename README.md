# BtBattery（蓝牙耳机状态栏电量显示）

一款极简、免 Root、无广告的 Android 小工具。专为支持标准蓝牙电量协议的第三方/通用蓝牙耳机打造，将耳机电量百分比直接以**纯数字图标**常驻显示在手机状态栏中。

## 核心特性

* **状态栏纯数字显示**：通过动态绘制透明底白字位图（`Canvas`）作为通知小图标，一眼看清电量（如 `80`、`20`）。
* **智能过滤非音频设备**：自动筛选已连接的 `AUDIO_VIDEO` 音频类蓝牙设备，不会被同时连接的手表、手环等设备顶掉电量显示。
* **极简低耗**：仅监听系统蓝牙连接与电量变化广播，无多余界面、无后台轮询、无任何联网权限。
* **云端自动打包**：内置 GitHub Actions 工作流，无需本地安装 Android Studio 即可编译 APK。

## 适用前提

* **系统要求**：Android 8.0 及以上（`minSdk 26`，已适配 Android 14 / 澎湃 OS）。
* **耳机要求**：耳机需支持标准蓝牙 HFP 电量上报协议。验证方法：连接耳机后，在手机 **设置 → 蓝牙** 中能看到该设备的电量百分比即可使用。

## 安装与使用

### 1. 获取 APK
1. 前往本仓库顶部的 **Actions** 页面，点击最近一次构建成功的 **Build APK** 记录。
2. 在页面底部的 **Artifacts** 区域下载 `BtBattery-APK`，解压后将 `app-debug.apk` 安装到手机。

### 2. 首次授权
打开桌面上的 **耳机电量** 图标，按提示授予 **附近设备（蓝牙连接）** 和 **通知** 权限。授权完成后界面会自动关闭，后台监听服务即刻生效。

### 3. 小米 / 澎湃 OS（HyperOS）必做设置
为确保状态栏正确显示动态数字且服务不被系统清理，请完成以下两项设置：

1. **开启原生通知图标（关键）**：
   * 进入 **设置 → 通知与状态栏 → 状态栏**，开启 **显示通知图标**。
   * 如果状态栏仍显示为普通 App 图标而非数字，请前往 **设置 → 通知与状态栏 → 通知显示设置**，将通知样式切换为 **原生（Android）**。
2. **防止后台被杀**：
   * 长按 App 图标 → **应用信息** → 开启 **自启动**，并在 **省电策略** 中选择 **无限制**。
