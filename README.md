# BtBattery（蓝牙耳机状态栏电量显示）

一款极简、免 Root、无广告、无联网权限的 Android 蓝牙耳机电量工具，专为小米澎湃 OS（HyperOS）及第三方通用蓝牙耳机（含倍思、奢音 SHEYIN X5 骨传导耳机等）深度优化。

## 核心特性

* **顶部状态栏动态贴片（绕过澎湃 OS 限制）**：通过系统悬浮层在桌面/应用顶部状态栏直接渲染实时电量图标，支持 **圆角徽章**、**环形仪表**、**电池框** 3 种样式，按剩余电量自动变色（绿 / 琥珀 / 红）；支持 X/Y 坐标与大小像素级微调，点击穿透不阻挡下拉，横屏看视频/游戏自动隐藏。
* **下拉通知栏高清进度卡片**：自定义 `RemoteViews` 卡片，一眼看清设备名、大号百分比与彩色进度条，无需二次点击展开。
* **多通道电量读取与耳机专项适配**：
  * 综合 `BluetoothHeadset` / `BluetoothA2dp` / `AudioManager` 实时识别活动音频设备，自动过滤同时连接的手表、手环。
  * 四层电量获取兜底：系统隐藏接口 `getBatteryLevel` → 系统电量广播 → HFP 厂商扩展 AT 指令（`+IPHONEACCEV`）→ BLE 标准电量服务（`0x180F`），特别适配 **SHEYIN X5** 等骨传导/第三方耳机。
  * 支持「自动识别」与「锁定特定耳机」自由切换。
* **后台隐藏与防杀守护**：
  * 支持 **最近任务隐藏卡片**，防止一键清理误杀。
  * 内置 **开机自启**、**应用更新自动恢复**、**非唤醒低耗守护巡检** 及 **系统电池优化白名单一键申请**。
* **GitHub Actions 云端自动构建**：无需本地安装 Android Studio，推送代码自动输出可直接安装的 APK。

## 适用前提

* **系统版本**：Android 8.0 及以上（`minSdk 26`，针对 Android 14 / 澎湃 OS 适配）。
* **耳机要求**：支持标准蓝牙 HFP 电量上报、`+IPHONEACCEV` 协议或 BLE 标准电量服务（`0x180F`）。

## 安装与配置指南

### 1. 下载安装 APK
1. 进入本仓库顶部的 **Actions** 页面，点开最新一次绿勾通过的 **Build APK** 记录。
2. 在页面底部 **Artifacts** 下载 `BtBattery-APK`，解压安装 `app-debug.apk`。

### 2. 开启顶部动态状态栏贴片
1. 打开桌面 **耳机电量**，授予 **附近设备（蓝牙连接）** 与 **通知** 权限。
2. 点击 **授予悬浮窗权限** 并为本应用开启开关。
3. 打开 **开启顶部状态栏贴片**，拖动水平 X / 垂直 Y / 大小滑块对齐到状态栏合适位置，并在下方切换喜欢的图标样式（圆角徽章 / 环形仪表 / 电池框）。

### 3. 澎湃 OS（HyperOS）去蓝标与防杀后台推荐设置
为了实现「**顶部只留动态电量图标 + 无蓝色耳机占位标 + 长期不被杀后台**」，建议在 App 的 **后台隐藏与防杀守护** 卡片内完成以下操作：

| 配置项 | 操作方式 | 作用 |
| :--- | :--- | :--- |
| **最近任务隐藏卡片** | 打开 App 内开关 | 不出现在多任务列表，防一键清理误划掉 |
| **防杀后台守护** | 打开 App 内开关 | 开机自启、覆盖更新自启、异常退出自动恢复 |
| **忽略电池优化** | 点「一键申请忽略电池优化」 | 加入 Android 系统 Doze 白名单 |
| **澎湃自启动** | 点「澎湃自启动」并开启 | 允许开机及后台拉起监听服务 |
| **省电无限制** | 点「省电无限制」并选 **无限制** | 防止澎湃 OS 墓碑机制清理后台进程 |
| **隐藏蓝色耳机标** | 点「通知设置(去蓝标)」关闭 **通知图标**（若连下拉卡片也不需要，直接关 **允许通知**） | 去掉澎湃 OS 强行显示的静态蓝色 App 图标 |
